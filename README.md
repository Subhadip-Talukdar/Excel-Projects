# Microsoft Excel Data Analytics & Financial Modeling Portfolio

A collection of end-to-end exploratory data analysis (EDA), Pivot Table reporting, relational lookup modeling, and payroll automation projects built in Microsoft Excel.

## Repository Structure

| # | Project Folder | Focus Areas & Excel Techniques | Dataset Scale |
| :--- | :--- | :--- | :--- |
| 01 | [`01-uber-trips-analysis`](./01-uber-trips-analysis) | Feature engineering, conditional KPIs (`COUNTIFS`, `SUMIFS`, `AVERAGEIFS`), Pivot Tables | 50,000 rows |
| 02 | [`02-everlasting-earrings-sales`](./02-everlasting-earrings-sales) | Date standardization, multi-level hierarchical Pivot Tables, regional & channel slicing | 300 rows |
| 03 | [`03-income-tax-payroll-model`](./03-income-tax-payroll-model) | Indian New Regime (FY 2024–25) progressive slab engine, Section 87A rebate, dynamic lookups | 12 employees + 18 tasks |
| 04 | [`04-indian-railways-fare-engine`](./04-indian-railways-fare-engine) | Relational data stitching (`VLOOKUP`, `HLOOKUP`, `XLOOKUP`, `INDEX`+`MATCH`), automated PNR billing | 40 trains, 28 stations, 25 PNRs |
| 05 | [`05-excel-lookup-practice`](./05-excel-lookup-practice) | Exact/approximate lookups, two-way matrix lookups, relative/absolute/mixed cell referencing | 6 datasets |

## Core Skills Demonstrated
- **Data Cleaning & Transformation**: Date parsing, logical flags (`IF`, `AND`, `OR`), error handling (`IFERROR`), timestamp arithmetic.
- **Lookup & Relational Modeling**: `XLOOKUP` (reverse search, dynamic arrays), `INDEX` + `MATCH` (two-way & multi-criteria), `VLOOKUP`, `HLOOKUP`.
- **Business Intelligence & Reporting**: Multi-dimensional Pivot Tables, conditional aggregations (`SUMIFS`, `COUNTIFS`, `AVERAGEIFS`), automated tax and fare calculators.
